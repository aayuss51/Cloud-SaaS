## ✨ Core Ecosystem Features

### 🌟 Premium Guest Portal
*   **Intelligent Booking Engine**: Validated check-in/out logic with instant cost synchronization and tax calculations.
*   **Liquid UI Components**: Smooth animations,iOS 26-inspired glassmorphism, and responsive layouts.
*   **AI Concierge (Mero Support)**: Context-aware assistant powered by **Google Gemini 3 Flash**, trained on your hotel's specific facilities and room types.
*   **Identity Sync**: Manage profile visuals, contact data, and personal preferences with a persistent registry.
*   **Financial Receipts**: Generate professional, printable PDF-style statements for every stay.

### 🛡️ Administrative Command Center
*   **Inventory Control**: CRUD operations for room categories including facility mapping and high-res visual assets.
*   **Operations Center**: Integrated task manager for housekeeping/concierge and a live activity feed of guest arrivals.
*   **Bulk Operations**: Mark multiple bookings as completed or cancelled with a single click via the floating Batch Action Bar.
*   **Granular Security**: Role-based access control (RBAC) separating Guest, Admin, and Super Admin permissions.
*   **Property Configuration**: Global control over hotel branding, tax rates, contact endpoints, and currency settings.

*   **Framework**: React 19 (Latest)

*   **Styling**: Tailwind CSS (JIT Compiler)
*   **Intelligence**: Google GenAI SDK (Gemini-3-Flash-Preview)
*   **Database**: Simulated Persistence Layer (LocalStorage Mock DB)
*   **Routing**: React Router DOM v7
*   **Icons**: Lucide React

## 🚀 Local Development

### Prerequisites
*   Node.js (v18+)
*   An API Key for Google Gemini (Set in your environment or via the UI)

### Setup & Run
1.  **Install Dependencies**
    ```bash
    npm install
    ```

2.  **Start Development Server**
    ```bash
    npm run dev
    ```

3.  **TypeScript Validation**
    To run the TypeScript compiler and verify type safety without building:
    ```bash
    npm run typecheck
    ```

4.  **Production Build**
    ```bash
    npm run build
    ```
